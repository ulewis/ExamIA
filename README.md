# ExamIA UPCH

Prototipo demostrativo de plataforma de exámenes virtuales para la Universidad Peruana Cayetano Heredia.

## Probar

Abra `index.html` en un servidor local o publique la rama `main` en GitHub Pages (carpeta raíz).

## Funcionalidades de demostración

- Roles simulados de administrador, docente y estudiante.
- Editor de exámenes y preguntas.
- Temporizador y corrección de preguntas cerradas.
- Cámara obligatoria opcional por examen, mediante permiso del navegador.
- Registro local de cambios de pestaña y resultados.

## Importante

No existe autenticación institucional real ni base de datos centralizada. Los datos se almacenan en el navegador del usuario. La detección de movimientos con IA aún no está implementada. No use este prototipo para evaluaciones oficiales ni ingrese datos personales reales.

## Pendiente para producción

Google OAuth verificado en servidor, autorización por roles, almacenamiento seguro compartido, IA local, pruebas de carga y privacidad de datos.
